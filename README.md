"Belajar Python Dasar" tutorial series (19 chapters). Each chapter is
committed separately and pushed to GitHub right after it is finished.

## Summary of the material

- Basics: program structure, comments, indentation, data types,
  variables, constants, and operators.
- Logic: if/elif/else, for and while loops, break and continue, and
  functions with default arguments, *args, and **kwargs.
- Data structures: list, tuple, set, and dictionary.
- Object-oriented programming: classes and objects, encapsulation,
  inheritance, polymorphism, and abstraction with ABC.
- Robust programs: exception handling with try, except, else, finally,
  and raise; reading and writing files with the with statement.
- Code organization: custom modules, built-in modules, and packages
  with __init__.py.
